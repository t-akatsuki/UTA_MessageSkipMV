# -----------------------------------------------------------------------------
# 利用方法
# -----------------------------------------------------------------------------
1. ご自身のプロジェクトの js/plugins 以下に「UTA_RPGMVZPluginTemplate.js」を配置します。
2. その後エディターの [ツール] > [プラグイン管理] からプラグインを有効にします。
3. 有効にしたプラグインのプラグイン設定から必要に応じてプラグインパラメータの設定を行う。

詳細な利用方法はプラグインの設定のヘルプから見られますのでご確認ください。
